# 🚀 PortfolioHUB

Bem-vindo ao repositório oficial do **PortfolioHUB**! 

Este projeto foi desenvolvido como parte da Entrega Final da disciplina de **Bootcamp I** do curso de Ciência da Computação. O objetivo principal é servir como uma vitrine digital centralizada para meus projetos de desenvolvimento, competências técnicas e conquistas acadêmicas.

🔗 **Acesse o projeto online:** [PortfolioHUB - Ao Vivo](https://arthur-morelo.github.io/PortifolioHUB/)

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído focando em fundamentos sólidos da web e boas práticas de versionamento:
* **HTML5, CSS3 e JavaScript (Vanilla)** para a estrutura, estilo e interatividade.
* **GitHub Pages** para hospedagem e deploy contínuo (CI/CD nativo).
* **Google Workspace API / Iframes** para integração de serviços em nuvem.

## ✨ Principais Funcionalidades e Integrações

* **Vitrine de Projetos:** Destaque especial para o projeto colaborativo **Walletly**, demonstrando habilidades práticas em desenvolvimento de software.
* **Integração com Google Workspace:** Implementação de um `iframe` seguro conectado ao Google Drive, exibindo em tempo real a pasta pública com minhas certificações e diplomas.
* **Design Responsivo:** A plataforma é adaptável para dispositivos móveis, tablets e desktops (Mobile First).
